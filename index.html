How to use this page

A checking page for the Admin. Nothing here changes a job.

1. Orders declined

Order numbers you declined to create from a document (only the number is saved). The Now column shows if the order has since been created in the system. Remove from list deletes the entry.

2. Jobs without a document

Real order numbers with an amount above 0 that have no PDF attached. Use Attach PDFs to add the missing files and Search Job No to find one job. When the list is empty, every job has a document.

3. Documents read

Each attached PDF is read for its order number, lot and amount, and compared with the job in the system. A row marked Check has a difference, with the reason under it. Open the document with View, then tick Reviewed once you have confirmed it. By default only rows that need checking are shown.

Double check

Reads only the PDFs that have no saved reading yet (PDF files up to 10 MB) and saves what it read for review. It asks you to confirm first. Jobs are not changed. Use Read again on a row to replace its reading.

Save PDF / Save Excel

Export the list above the button, as a PDF or as an Excel-ready file, for example to send the missing documents to the auditor.

Before closing a period

  1. Press Resync to load the latest data.
  2. Attach the missing PDFs.
  3. Press Double check, then clear every Check row.
  4. Save the PDFs you need.
  5. Then issue the Official PDF Report.
